# VU3INI-PDF-SwissKnife
Offline-first, all-in-one PDF toolkit for Windows 10/11. Merge, split, edit, redact, fill forms, convert (Word, Excel, PowerPoint, Markdown), compress, PDF/A, digital signatures, AES encryption, OCR in 21 languages including Assamese and Hindi, translation, and chat-with-PDF AI. Your files never leave your PC.
